# WRC Sauna MM

WRC Sauna MM võistluste, tulemuste ja sõitjate veebirakendus.

## Tehnoloogia

- Firebase Hosting
- Firebase Authentication
- Firebase Realtime Database
- HTML, CSS ja JavaScript

Avaldatud leht: https://wrc-mm.web.app/

## Avaldamine

```powershell
firebase deploy
```

Firebase'i projekt on määratud failis `.firebaserc` ja andmebaasi turvareeglid failis `database.rules.json`.
